# Betty Pet

一个以 Python/Tkinter 为基础的高自定义桌宠原型。当前支持透明置顶窗口、重力与投掷物理、跟随鼠标、
拖拽、右键菜单、缩放、随机动作、对话气泡、SQLite 存档、按 manifest 管理动画素材、窗口栖息、
沿墙与天花板攀爬、系统托盘、专注计时和音效（winsound 后端 + 合成占位音）。

## 交互

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 拎起宠物；松手时按拖拽速度决定是「放下」还是「扔出去」 |
| 左键单击 | 触发 click 动作与随机台词 |
| 鼠标悬停 0.8 秒 | 打招呼 |
| 滚轮 / 右键「放大 / 缩小」 | 缩放（0.3~2.5 倍，写入存档） |
| 右键菜单 | 喂食 / 玩耍 / 休息（子菜单标出今日剩余次数）、跟随鼠标、音效开关、跳到窗口 / 离开窗口、爬左墙 / 爬右墙 / 上墙（天花板）/ 离开墙面、专注 25 分钟 / 结束专注 / 专注统计、状态面板 / 调试面板、隐藏到托盘、历史记录、退出 |
| 双击托盘图标 | 显示 / 隐藏宠物 |
| 右键托盘图标 | 显示 / 隐藏、跟随鼠标、退出 |

宠物从屏幕右下角出现并站在地面上；被扔出去会走抛物线、撞墙和落地都会带阻尼反弹，最终停下。
「跟随鼠标」打开后会朝光标走过去，靠近到死区内自动停下（防止来回抖动）。

## 自主行为

不用指挥，贝蒂会自己过日子：每 6~15 秒按「需求阈值 + 权重」随机选一个动作——饿了蹭嘴、
没电了坐下、心情好挥手，深夜（默认 23 点到早上 7 点）有一定概率直接打盹说晚安；
被扔出去落地后会坐下抱怨。没人陪超过 5 分钟，她会自己打个盹嘟囔一句「有人吗……」，
任何接触都会重置这个计时。这些参数都在 `AppConfig`（`neglect_minutes` / `nap_hour_start`
/ `nap_hour_chance` / `action_rerolls`）。

**调试面板**（右键菜单「调试面板」）是这套逻辑的透视镜：实时状态、行为规则逐条列出
`✓/✗ + 条件 + 权重`，滑杆直接改饱腹/心情/精力看规则亮灭，「随机行为 ×1」「触发打盹」
「重置数值」一键触发，每个已注册动作都有独立播放按钮。

## 养成

道具表在 `src/betty_pet/items.py` 的 `default_items()`，加一条就是加一个菜单项。

| 道具 | 分组 | 效果 | 今日上限 |
| --- | --- | --- | --- |
| 饼干 | 喂食 | 饥饿 −18，心情 +3，好感 +1 | 6 |
| 小鱼干 | 喂食 | 饥饿 −35，心情 +6，好感 +2 | 3 |
| 热茶 | 喂食 | 饥饿 −10，精力 +10，心情 +3，好感 +1 | 5 |
| 毛线球 | 玩耍 | 心情 +16，精力 −8，好感 +2 | 4 |
| 逗猫棒 | 玩耍 | 心情 +12，精力 −5，好感 +3 | 5 |
| 打个盹 | 休息 | 精力 +35，心情 +2，好感 +1 | 3 |

**宠物会拒绝。** 吃饱了（饥饿 ≤ 20）会说「吃不下啦」；当日次数用尽会说「今天已经吃够了」；
冷却没到会说「等一下嘛」。这三种拒绝都不消耗次数。

好感度每 50 点升一级：陌生 → 熟悉 → 朋友 → 好友 → 亲密 → 挚友。好感度**不会随时间衰减**，
升级时会说出来并写进事件日志。每日次数、好感度都在 SQLite 存档里，跨天自动重置。

## 专注

右键「专注 25 分钟」（或用 `python main.py --focus`）开始一次番茄钟。宠物会**坐下不动**：
随机动作停掉、不追鼠标、悬停也不打招呼，状态面板里多出一行 `专注 1/2　24:57` 的倒计时。

一次专注默认跑 **2 轮**（`focus_rounds`）：每轮 25 分钟专注 + 5 分钟休息，轮与轮之间自动衔接，
状态面板会变成 `专注 2/2`。**每 2 轮的休息是一次长休**（`focus_long_break_minutes`，默认 15 分钟，
面板显示 `长休`）。全部轮次走完，它自己回到常态。中途用「结束专注」退出**什么也拿不到**——
专心坐满才算数，否则这就只是个按钮。

每坐满一轮，它会高兴一下、说一句鼓励的话、**好感度 +3**。累计完成的轮次记在存档里
（`settings` 表的 `focus_completed_total`），重启不会清零；当日次数另记在 `daily_usage`，
午夜重置。`focus_long_break_every` 设 0 可以关掉长休。

这是目前**最不依赖菜单的好感度来源**（另一个是戳一戳它），用来奖励真的在做事。时长在
`config.py` 的 `focus_minutes` / `focus_break_minutes`，命令行 `--focus-minutes` 只覆盖前者。

实现上只有一张牌：`play(idle)` 会回到 `self._rest_action` 这个"静止姿态"。专注期间把它从
`idle`（站着）换成 `sit`（坐着），于是任何动作结束、任何随机打断之后，宠物都会自己坐回去，
不需要为"保持坐姿"再加一个定时器。`focus.py` 里的 `FocusTimer` 是纯状态机，不碰 Tkinter。

## 窗口栖息

右键「跳到窗口」，宠物会站到**当前前台窗口的上沿**（xiaohei-desktop-pet 与 Shimeji 都有这个行为）。
之后它会待在窗口上，窗口移动或缩放会跟着走；窗口被关闭、最小化，或者被拖到贴着屏幕顶部时，
它就会掉下来落回地面。「离开窗口」也可以主动让它跳下来。

实现上没有为栖息新增任何物理：窗口上沿被折算成一个临时的 `Bounds` 交给原来的物理步进，
所以站在窗口上、沿窗口边缘行走、掉回地面，用的都是既有那套重力/摩擦/反弹。
细节上：抓起来拖走会脱离窗口（单击不会），轨迹由探测器按进程号排除了宠物自己。

**不支持最大化窗口**——它的上沿就在屏幕最顶端，宠物没地方站，与其让它盖住你的标题栏和关闭按钮，
不如直接拒绝。多显示器也还没处理，只有主屏幕边界。

## 沿墙与天花板攀爬

宠物在地面朝屏幕边缘走时会**自动抓住墙**（也能从右键菜单直接「爬左墙 / 爬右墙 / 上墙」）。
抓住之后往上爬，爬到墙顶会**翻到天花板**上继续横穿，走到另一端再**顺着另一侧墙下来**，
爬到底就落回地面。随时抓起拖走都会打断攀爬、掉回地上。

屏幕边缘不是一条线，而是一条 **60px 宽的可攀附带**：带内重力挂起，宠物可以沿着墙上下爬、
也可以朝屏幕内侧挪一挪；**顶到带的内缘、抓不住了才掉下来**——是自然下落，不是瞬移。
所以它偶尔会自己从墙上滑下来，这是设计的一部分，不是 bug。

同样没有为攀爬加新的运动代码：天花板把矩形压成**零高的一条线**、墙压成**一条 60px 宽的竖带**，
交给原来的物理步进，"不许出框"就自动变成了"钉在带上、沿线滑动"。
攀爬期间跳过重力（挂着不是踩着），阻尼改用地面摩擦，所以松手是"停下"而不是"滑翔"。

**素材已配齐**：沿墙（`climb_wall_left` / `climb_wall_right`，左右两帧互为镜像）、
天花板（`walk_ceiling`）都有专属帧，由 AI 生成后抠图接入。完整设计与踩坑见
[攀爬设计草案](docs/CLIMBING_DESIGN.md)。

## 系统托盘与开机自启

托盘图标用 pywin32 直接创建（`Shell_NotifyIcon`），**不依赖 pystray**。任务栏不可用或没装 pywin32 时，
程序会照常启动，只是没有托盘——此时右键菜单里的「隐藏到托盘」会拒绝执行并说明原因，免得宠物藏到找不回来。

开机自启是**显式命令**，不会自己写：

```powershell
python main.py --autostart-status        # 只看状态，不写任何东西
python main.py --install-autostart       # 写入「启动」文件夹的 BettyPet.vbs
python main.py --uninstall-autostart     # 删掉它
```

写的是一个 `.vbs` 启动器（`pythonw` 拉起，开机不弹黑框），位置在
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\BettyPet.vbs`——看得见、删一个文件就彻底撤销。

## 音效

音效已**能出声**：`src/betty_pet/audio.py` 提供 `SoundPlayer` 协议与语义键位；
Windows 上默认用 `WinsoundPlayer`（标准库 `winsound`，异步播放 `assets/sounds/<key>.wav`，
不阻塞 UI，缺文件静默跳过），非 Windows 自动回退到只记录不发声的 `SilentPlayer`。
菜单「音效」开关和 `--sound` / `--no-sound` 控制开关。

现在的 11 个音色是**程序合成的占位音**（`tools/synth_sfx.py`，纯标准库，可改参数重新
生成）：点按是短促的"嗒"、拒绝是低沉的"womp womp"、升级是四音小号角、专注开始/结束
各有温柔的和弦。想要真音效，用同名 WAV 覆盖 `assets/sounds/` 里的文件即可，不用改代码。

要真正响起来需要两步：一个后端（实现 `SoundPlayer.play(key)` 即可，调用点不用改），以及一批音频文件。

## 准备环境

```powershell
conda activate pic
conda env update -f environment.yml
python -m pip install -e .
```

桌宠运行核心依赖是 Pillow；`png_process.py` 需要 OpenCV 和 NumPy，`environment.yml` 已包含。Windows 可用 `python -m tkinter` 检查 Tkinter。

## 运行

```powershell
python main.py
python main.py --check-assets
python main.py --scale 1.25 --no-random
python main.py --status                      # 打印存档状态与最近事件后退出
python main.py --db ./betty.db               # 指定 SQLite 存档位置
python main.py --no-persist                  # 本次运行不读写存档
python main.py --no-sound                    # 本次运行强制关闭音效（--sound 为强制开启）
python main.py --focus                       # 启动后立刻开始一次专注
python main.py --focus --focus-minutes 50    # 启动后立刻开始一次 50 分钟的专注
python main.py --autostart-status            # 查看开机自启状态（只读）
```

## 目录约定

```text
src/betty_pet/
  config.py       运行配置
  assets.py       素材清单和加载
  model.py        与界面无关的动作状态机
  state.py        宠物状态、好感度、衰减
  items.py        道具表与使用规则（含拒绝条件）
  focus.py        专注计时的纯状态机（专注 → 休息 → 结束）
  behavior.py     阈值行为、语言接口和模板实现
  movement.py     移动计划、边界目标与追鼠标方向
  physics.py      重力、摩擦、阻尼反弹、拖拽投掷速度、贴合面（Surface）
  desktop.py      探测前台窗口，把窗口上沿折算成栖息面
  audio.py        音效协议、静音实现与 winsound 后端（键位即接口）
  tray.py         pywin32 自绘托盘图标（无依赖时自动降级）
  autostart.py    开机自启启动器的生成与安装（仅显式命令调用）
  scheduler.py    定时器调度（优先级、分组取消、冷却）
  store.py        SQLite 存档、设置和事件日志
  window.py       Tkinter 窗口和交互
  __main__.py     CLI 入口
assets/           已处理、可直接使用的 PNG 和 manifest.json
input/            原始素材
output/           png_process.py 的处理结果
```

## 存档

默认存档位置是 `~/.betty_pet/state.db`，四张表：`pet_state`（数值、好感度与时间戳）、`settings`（缩放、跟随鼠标、音效等偏好）、`event_log`（启动/关闭/喂食/升级/栖息/攀爬/专注事件，自动裁剪保留最近 500 条）、`daily_usage`（按本地日期分桶的每日次数，专注次数也记在这里）。启动时读取并按离线时长补算自然衰减，运行中每分钟自动保存，退出前再保存一次。存档不可用时自动降级为内存存档，不影响启动。旧存档会自动补上新增的列，不需要手动迁移。

## 素材

新增动作时，在 `assets/manifest.json` 增加动作名和 PNG 文件列表即可。

物理与交互动词的专属素材（`dragged` / `fall` / `thrown` / `chase_mouse`，以及攀爬三向）
已由「AI 生成 → 云抠图」流水线补齐，且多数动作有两帧可交替播放。

流水线记录（复用要点）：ImageGen 以 `stand.png` 做角色参考（`input_fidelity: high`），
**`background:"transparent"` 参数不生效**——返回全不透明 RGB，必须再走云抠图得到透明
背景；并发生成会给不同图起同一个输出文件名、互相覆盖，**每张生成后立即改名**；
提示词里要明确「无玻璃框/无边框/纯白底」，否则模型会给贴墙姿势画上一个玻璃板。
原始图与抠图中间产物在 `input/ai/`。
